Managed Copilot

Run GitHub Copilot agents in environments you own: on your laptop, or in your Azure subscription.
A tour of what we built · stock GitHub Copilot SDK 1.0.26 and runtime 1.0.103 · Aspire · Azure Container Apps
The idea

Same Copilot SDK. Your environment.

import { approveAll } from "@github/copilot-sdk"; import { ManagedCopilot } from "@managed-copilot/sdk"; const managed = await ManagedCopilot.connect(); // your platform const client = await managed.client("chat"); // a stock CopilotClient const session = await client.createSession({ model: "claude-sonnet-5", onPermissionRequest: approveAll, }); const reply = await session.sendAndWait({ prompt: "Summarize what changed" });
  • Genuine CopilotClient and CopilotSession objects
  • The published SDK and runtime, unmodified
  • Two setup lines point it at your platform
  • The platform decides where agents run and what they reach
Environments

Three kinds of environments

Shared

A lightweight chat agent on a shared runtime. Its tools run inside your app.

type: "shared"

Isolated

Every session gets its own sandbox: a workspace, a shell, your packages, and network rules you control.

type: "isolated"

Promotable

Starts cheap on the shared runtime, then moves into its own sandbox when it needs one.

type: "promotable"
// apphost.mts: declared once, picked by name await addManagedCopilot(builder, "copilot", { environments: { chat: { type: "shared", network: ["learn.microsoft.com"] }, coder: { type: "isolated", size: "medium" }, helper: { type: "promotable", promoteTo: "coder" }, } });

Gateway

You run it: locally or on Azure

  • Signs you in with GitHub
  • Routes each session
  • Durable record of tool calls and approvals
  • Network and secrets policy
  • Brokers model calls

Models

Through your own GitHub Copilot plan

Shared runtime

Lightweight chat sessions

Sandboxes

One per isolated session: workspace, shell, packages

Egress proxy

Allowlists · secrets added at the edge

Internet and APIs

Only what you allow

Your GitHub token never enters a sandbox
